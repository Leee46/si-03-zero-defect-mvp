# SI-03 Zero-Defect Manufacturing System (MVP)

This is a **Phase 1 MVP** of a vision-based defect detection and causal analysis system for manufacturing.

## Features

- Defect Detection via CNN
- Defect Classification
- Basic Causal Analysis
- Dashboard UI
- REST API
- Docker Deployment

## Setup

1. Clone repo
2. Install dependencies
3. Run `python models/defect_model.py` to train model
4. Run `flask run` to start API
5. Access dashboard at `http://localhost:5000`

## Docker

Run with `docker-compose up --build`
